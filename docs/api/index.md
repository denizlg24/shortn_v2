# Shortn developer documentation

Manage workspace links, QR codes, campaigns, tags, bio pages and domains through the Shortn API.
API access and outgoing webhooks are being rolled out behind workspace feature flags.

- [Getting started](/docs/getting-started): authentication, requests, pagination and errors.
- [Link schedule and query rules](/docs/link-rules): activation, expiry, fallback, forwarding and UTM.
- [Bulk link creation](/docs/bulk-links): atomic batches, quota errors and retries.
- [Interactive API reference](/docs/api): endpoint schemas and request examples.
- [API reference in markdown](/docs/api.md): all implemented endpoints and schemas.
- [Outgoing webhooks](/docs/webhooks): subscriptions, signatures, delivery and retries.
- [MCP integration status](/docs/mcp): availability and setup status.
- [OpenAPI specification](/openapi.json): machine-readable API contract.

Every documentation page also has a `.md` version. Use [llms.txt](/llms.txt)
for a compact index or [llms-full.txt](/llms-full.txt) for the complete documentation.
