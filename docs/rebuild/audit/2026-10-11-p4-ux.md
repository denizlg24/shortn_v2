# P4 UX implementation checkpoint — 2026-10-11

P4 remains in progress. This checkpoint records local evidence, not staging sign-off or completion of the parity checklist in `16-p4-breakdown.md`.

## Implemented in this pass

- Link creation/editing and QR creation/editing share a searchable tag picker. Selected tags are removable chips; new tags are created in the picker and submitted as repeated `tag` fields.
- Link list filtering accepts multiple tags through repeated URL parameters, using the existing service's any-match semantics. QR tags and analytics link/dimension filters are searchable comboboxes. Analytics controls are grouped by period, activity, location, technology and acquisition.
- Filter labels use unique React IDs. Search fields reset when the URL is cleared. Multi-select popovers remain open across filter navigation, and URL navigation restores selections.
- Link and bio overviews expose sharing through Web Share, with clipboard fallback and localized feedback. Dismissing the native share sheet does not copy unexpectedly.
- Missing account pages now exist at `/settings/account/email`, `/password`, `/sign-in` and `/sessions`. The account root is the profile page. Each page requires workspace access; OAuth linking returns to the sign-in page.
- Settings/workspace/member/billing messages referenced by the rewritten pages are present in English, Portuguese and Spanish. Shared UI controls support Spanish rather than falling back to English.
- Translation tests parse ICU messages, including nested plural/select arguments, rather than mistaking translated branch text for placeholders.

- Link and QR created-time filters now support custom UTC date ranges, including one-sided bounds and inclusive end dates. Presets clear the custom dates; changes retain other filters and reset pagination.
- Link overview includes its activity time series and uses the shared analytics plan gates/history limits. Analytics link selection searches the workspace rather than the first 200 links.
- Root `bun run dev` explicitly loads `.env.staging`, launches web/redirect/API/worker, and starts dedicated local Docker dependencies when their URLs are absent. `bun run dev:check` validates without starting services.
- Persistent `apps/web/e2e/controls.browser.ts` creates and removes its own local fixture route, checks tag/filter/share interactions, and covers locale/theme/viewport combinations.

- UTM removal now has its own confirmation page, localized consequences and failure feedback. The saved list shows a removal notice. UTM create/edit pages enforce editing permission and explain the plan requirement before presenting a form.
- UTM changes compare the form’s original variants and atomically reject concurrent replacements. Failed saves preserve fields, and adding a 51st variant reports the limit instead of silently discarding it.
- Translation coverage now checks literal `useTranslations`/`getTranslations` calls in source against the catalog as well as catalog parity, so a literal key absent from all three languages is caught. Dynamic message calls still need runtime coverage.

- The shell now resolves workspace plan labels from current subscriptions, matching billing and feature gates. It previously displayed a stale “Free plan” beside Pro usage limits. The workspace switcher loads subscriptions in one query.
- Added `test:dashboard`: an authenticated production-build browser suite using disposable local MongoDB data, generated credentials, and local Redis. It signs in through the real login form and cleans up its database/server afterward. Setup is documented in the root README.

- Both UTM editors now use searchable saved-value suggestions beside editable inputs. The link variant form offers source/medium/term/content defaults for its selected campaign; changing campaigns retains custom input. The campaign builder no longer renders every default as a button wall. Added en/pt/es suggestion labels and instructions.
- Single-select comboboxes clear their search after selection, so reopening the menu starts with all choices.
- Added `test:flows`, which runs the authenticated suite plus public link tests against the real redirect process with generated shared secrets. It uses the disposable local database, validates port availability, stops both app processes and removes its own click events during cleanup.

- Bio link rows wrap long custom keys without covering reorder/remove controls. Social URL fields stack below their platform on phones. Editing a bio link draft clears stale validation errors, so reordering cannot mark a different link as invalid.
- The bio preview loads only complete HTTP image URLs while typing and stretches custom backgrounds through the phone frame.

- Shared form field errors now announce their feedback to screen readers. QR logo previews reject partial/non-HTTP URLs before attempting image requests.
