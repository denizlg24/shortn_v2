# Managing links

The Links page is built for large libraries. You can search and filter on the server, select links across pages and apply one change to all of them, archive links you no longer need in view, and restore deleted links within 30 days.

## Find links

Open **Links** in the sidebar. The list shows 25 links per page, with **Previous** and **Next** to move between pages. Use the filters above the list:

- **Search**: matches the key, destination or title.
- **Tag**: pick one or more tags. The tag list searches every tag in the workspace, so it works even with hundreds of tags.
- **Status**: show only links that are **Password-protected**, that **Shows safety page**, or that are **Disabled**.
- **Created**: limit the list to a recent period or a custom date range.
- **Sort by**: **Newest first**, **Oldest first** or **Most clicks**.

Filters are part of the page address, so you can bookmark or share a filtered view.

A **Destination error** flag on a row means weekly checks of that destination returned errors. The checks are informational; the link keeps redirecting.

## Edit a link

1. Select the link to open its overview.
2. Open the **Edit** tab.
3. Change the destination, key, title, description, tags, password or advanced options.
4. Select **Save changes**.

Changes apply from the next click. If you change the key, the old key keeps redirecting to the same link.

## Select links across pages

Tick the checkbox on each row you want, or use **Select this page**. Your selection stays as you move between pages and change filters, so you can build it from several searches. The selection bar shows how many links are selected and the maximum for one action. Use **Clear selection** to start again.

## Bulk actions

With links selected, choose an action. Each one opens its own page where you can review the selected links, filter that review, and confirm. Filters on the review page only change what you see; the action applies to the whole selection.

- **Edit tags**: choose an **Operation**, either **Add tags**, **Remove tags** or **Replace all tags**, pick the tags, then select **Apply tag changes**. **Remove all tags** clears every tag from the selection.
- **Move to campaign**: choose a **Destination campaign** and select **Move selected links**. Each link keeps its UTM source, medium, term and content. This needs a plan with campaigns.
- **Archive**: moves the links out of the active list. See below.
- **Delete selected**: moves the links to Trash.

Members can delete only the links they created. If your selection includes other people's links, the delete page tells you how many it can delete.

## Archive

Archiving tidies the active list without breaking anything. Archived links keep redirecting, and they stay in their QR codes, campaigns and bio pages. Their analytics remain.

To see them, select **Archived** above the list. Select links there and choose **Unarchive** to return them to the active list.

## Delete and restore

Deleting a link stops its short URL immediately, including on printed QR codes. For 30 days:

- the link stays in **Trash**, and you can restore it with its key, settings, campaigns and bio page references;
- its key stays reserved, so nobody else can take it.

After 30 days the link is permanently removed. Aggregate analytics remain.

To restore links:

1. Select **Trash** above the list. The **Restore until** column shows each link's deadline.
2. Select the links you want, across pages if needed.
3. Select **Restore selected**.

In Trash and Archived you can also choose **Group this page** and **By first tag** to group the current page by tag.

## Export

Select **Export** on the Links page to prepare a file of every link that matches your current filters, across all pages. A CSV export can be imported back into Shortn later.
