# Creating QR codes

Every QR code in Shortn opens a short link. The pattern printed on paper never changes, so you can change where the code goes after printing and still count every scan. This guide covers creating a code and getting a first file out.

## Before you start

Each QR code you create counts towards your plan's monthly QR code limit, shown under **Usage** in the sidebar. A code can point at:

- **a URL**: Shortn creates a short link for the code;
- **one of your links**: the code is attached to that link and opens it.

## Create a QR code

1. Open **QR codes** in the sidebar and select **New QR code**.
2. Under **Destination URL**, enter where a scan should take people. To use an existing link instead, select **Choose a link** under **Or use one of your links:** and pick it from the list. **Use a URL instead** switches back.
3. Optionally add a **Title** to help you find the code later, and **Tags**.
4. Select **Create QR code**.

The code's overview opens. The preview on the form uses a sample short link; your code gets its own short link when you create it.

You can also start from a link: open the link, select its **QR code** tab and select **Create a QR code**. The code is attached to that link, and you'll find it on that tab afterwards. If the link already has a code, the new one replaces it as the link's code, and the old code keeps scanning.

## Design the code

Select **Edit design** on the overview, or open the **Design** tab. You can change the colours, pattern, corner styles, error correction, logo, frame and caption. The scan check on the same page warns you about low contrast or a logo that is too large. Select **Save design** when you're done.

Design changes never change the link inside the code. [Managing QR codes](/docs/en/guides/qr-codes/managing-qr-codes) explains each option.

## Download the code

On the overview, under **Download**, select **Export for print**:

1. Choose a **Format**: SVG, PNG or PDF. SVG is a vector format and scales to any print size.
2. Choose a **Size** in pixels.
3. Select **Prepare download**, then **Download file** when it is ready.

The export page shows the recommended minimum print size for the code. For screens and email, open **JPEG for screens** on the overview.

## Test before you print

- Scan the downloaded file with two or three different phones.
- Keep clear space around the code; frames and captions are placed outside it.
- Keep strong contrast between the code and its background, with a dark code on a light background.
- Don't print the code smaller than the recommended minimum size.
- Add a short call to action near the code so people know what they'll get.

## Change the destination later

Open the **Details** tab, change the **Destination URL** and select **Save details**. Printed copies follow the new destination from the next scan. If the code is attached to a link, select **Also update the link** to copy the new destination or title to that link too.
