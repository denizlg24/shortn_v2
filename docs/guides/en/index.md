# Shortn guides

These guides walk through the Shortn dashboard task by task: creating and organising short links, designing QR codes for print, publishing bio pages, grouping links into campaigns, reading analytics and managing your plan. Each guide uses the labels you see in the app, so you can follow along with the dashboard open.
