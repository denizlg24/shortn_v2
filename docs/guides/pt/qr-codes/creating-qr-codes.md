# Criar códigos QR

Cada código QR do Shortn abre um link curto. O padrão impresso nunca muda, por isso é possível alterar o destino depois de imprimir e continuar a contar cada leitura. Este guia explica como criar um código e obter o primeiro ficheiro.

## Antes de começar

Cada código QR criado conta para o limite mensal de códigos QR do plano, visível em **Utilização** na barra lateral. Um código pode apontar para:

- **um URL**: o Shortn cria um link curto para o código;
- **um dos seus links**: o código fica associado a esse link e abre-o.

## Criar um código QR

1. Abra **Códigos QR** na barra lateral e selecione **Novo código QR**.
2. Em **URL de destino**, indique para onde a leitura deve levar. Para usar um link existente, selecione **Escolher um link** em **Ou use um dos seus links:** e escolha-o na lista. **Usar um URL** volta à opção anterior.
3. Acrescente, se quiser, um **Título** para encontrar o código mais tarde, e **Etiquetas**.
4. Selecione **Criar código QR**.

Abre-se o resumo do código. A pré-visualização do formulário usa um link curto de exemplo; o código recebe o seu próprio link curto quando é criado.

Também é possível partir de um link: abra o link, selecione o separador **Código QR** e depois **Criar um código QR**. O código fica associado a esse link e passa a aparecer nesse separador. Se o link já tiver um código, o novo passa a ser o código do link, e o antigo continua a funcionar.

## Desenhar o código

Selecione **Editar design** no resumo ou abra o separador **Design**. Pode alterar as cores, o padrão, os cantos, a correção de erros, o logótipo, a moldura e a legenda. A verificação de leitura na mesma página avisa quando o contraste é baixo ou o logótipo é demasiado grande. No fim, selecione **Guardar design**.

As alterações de design nunca mudam o link dentro do código. O guia [Gerir códigos QR](/docs/pt/guides/qr-codes/managing-qr-codes) explica cada opção.

## Transferir o código

No resumo, em **Transferir**, selecione **Exportar para impressão**:

1. Escolha o **Formato**: SVG, PNG ou PDF. O SVG é vetorial e adapta-se a qualquer tamanho de impressão.
2. Escolha o **Tamanho** em píxeis.
3. Selecione **Preparar transferência** e, quando estiver pronto, **Transferir ficheiro**.

A página de exportação indica o tamanho mínimo de impressão recomendado para o código. Para ecrãs e e-mail, abra **JPEG para ecrãs** no resumo.

## Testar antes de imprimir

- Leia o ficheiro transferido com dois ou três telemóveis diferentes.
- Mantenha espaço livre à volta do código; as molduras e as legendas ficam fora desse espaço.
- Mantenha um contraste forte entre o código e o fundo, com código escuro sobre fundo claro.
- Não imprima o código abaixo do tamanho mínimo recomendado.
- Junte ao código uma frase curta que diga o que se obtém ao lê-lo.

## Mudar o destino mais tarde

Abra o separador **Detalhes**, altere o **URL de destino** e selecione **Guardar detalhes**. As cópias impressas seguem o novo destino a partir da leitura seguinte. Se o código estiver associado a um link, selecione **Atualizar também o link** para copiar o novo destino ou título também para esse link.
