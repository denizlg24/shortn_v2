# Personalizar páginas bio

O editor de páginas bio trabalha sobre um rascunho: altera as secções, o tema e as definições, confirma na pré-visualização em direto e publica quando estiver pronto. Este guia descreve cada parte do editor, o agendamento, as versões e a ligação de um domínio próprio.

Abra uma página bio e selecione **Editar página bio**. A barra de ferramentas tem **Adicionar secção**, **Secções**, **Tema**, **Definições da página** e **Histórico**.

## Secções

Selecione **Adicionar secção** para acrescentar uma destas:

- **Perfil**: avatar, título, descrição e alinhamento. É possível escolher a forma do avatar.
- **Link**: um botão para um link. Ative **Destacar este link** para o fazer sobressair e acrescente uma miniatura.
- **Links**: um grupo de links. Selecione **Gerir links** para filtrar por etiquetas, pesquisar, selecionar links em várias páginas e acrescentá-los de uma vez. Em **Apresentação dos links**, escolha um esquema como lista vertical, cartões paginados ou grelhas de imagens.
- **Redes sociais**: ícones com ligação para os seus perfis noutras plataformas.
- **Título de secção** e **Texto**: títulos e parágrafos curtos entre os links.
- **Imagem**: uma imagem com descrição e ligação opcional.
- **Conteúdo incorporado**: conteúdo do YouTube, Spotify, SoundCloud, Vimeo ou Apple Music. Os visitantes veem um botão para o carregar, com a indicação de que isso partilha o endereço IP com o fornecedor.
- **Código QR**: um código QR para um dos seus links.

Selecione uma secção na pré-visualização para a editar e arraste a pega para mudar a ordem. **Secções** lista todas as secções pela ordem atual.

## Mostrar secções de forma agendada

Cada secção tem o interruptor **Visível** e as datas opcionais **Mostrar a partir de (UTC)** e **Mostrar até (UTC)**. Servem, por exemplo, para mostrar um link de bilhetes só durante um evento, ou para esconder uma secção sem a apagar. O agendamento está disponível nos planos pagos.

## Tema

Abra **Tema** para mudar o aspeto da página:

1. Escolha um **Tema predefinido** como ponto de partida, ou **Personalizado**.
2. Ajuste as cores: **Fundo**, **Superfície**, **Texto** e **Destaque**.
3. Escolha o **Tipo de letra**, o **Estilo dos botões**, o **Raio dos cantos** e o **Espaçamento**.
4. Acrescente, se quiser, uma **Imagem de capa (opcional)** por trás do perfil.

Os temas têm limites para que as páginas se mantenham legíveis. Se o contraste do texto for insuficiente, o editor avisa; selecione **Usar cor acessível** para o corrigir.

## Definições da página

Em **Definições da página** estão as opções que valem para a página inteira:

- **Identificador**: o nome da página no endereço. Selecione **Alterar identificador** para o mudar; os endereços anteriores continuam a funcionar.
- **Idioma da página**: o idioma em que a página está escrita.
- **Ocultar rodapé Shortn**: retira o rodapé "Criado com Shortn". Disponível nos planos pagos.
- **Aspeto na pesquisa**: ative **Ocultar dos motores de pesquisa** para manter a página fora dos resultados de pesquisa.

## Rascunhos e publicação

As alterações são guardadas no rascunho pouco depois de parar de escrever, e é possível guardar a qualquer momento com **Guardar rascunho**. A pré-visualização mostra o rascunho; os visitantes continuam a ver a página publicada até selecionar **Publicar**.

## Versões

Cada publicação cria uma versão. Abra **Histórico** para ver as **Versões publicadas (últimas 20)**. Para voltar atrás, selecione **Restaurar versão … como rascunho** na versão pretendida. A versão é copiada para o rascunho; selecione **Publicar** para a tornar pública de novo.

## Usar um domínio próprio

Uma página bio pode ser servida a partir de um domínio próprio, como `links.exemplo.pt`, com o extra de domínio personalizado. Cada extra inclui um domínio.

1. Abra **Definições** e selecione **Domínios**.
2. Se não tiver domínios disponíveis, selecione **Comprar extra de domínio**.
3. Em **Adicionar domínio**, indique o **Nome do domínio**, escolha a opção em **Usar para**, escolha a **Página bio** e selecione **Adicionar domínio**.
4. Siga as **Instruções DNS**: crie no fornecedor de DNS o registo CNAME indicado. Para um domínio de raiz, use CNAME flattening.
5. Aguarde até o estado mudar para **Ativo**. Se a verificação falhar, confirme o registo e selecione **Repetir verificação**.

Só quem pode gerir a faturação pode adicionar domínios.
