# Criar páginas bio

Uma página bio reúne os seus links numa única página pública, do tipo que se coloca no perfil de uma rede social. Os visitantes veem o perfil, os links e as restantes secções que acrescentar, e cada clique é contado. Este guia explica como criar uma página e publicar a primeira versão.

## Antes de começar

O número de páginas bio por espaço de trabalho depende do plano; a lista de páginas bio mostra quantas já estão em uso. Os links de uma página bio são links normais do Shortn, por isso aparecem em **Links** e nas estatísticas como os restantes.

## Criar uma página

1. Abra **Páginas bio** na barra lateral e selecione **Nova página de bio**.
2. Em **Endereço**, indique o endereço que as pessoas vão visitar: de 3 a 63 letras minúsculas, números e hífenes. O Shortn verifica se está livre enquanto escreve.
3. Indique, se quiser, um **Título**, mostrado no topo da página. Se o deixar vazio, é usado o endereço.
4. Em **Primeiro link**, pode selecionar **Escolher um link** para colocar já um dos seus links na página.
5. Selecione **Criar página**.

Abre-se o resumo da página, com **Copiar URL** e **Abrir página** para o endereço público.

## Construir a página

No resumo, selecione **Editar página bio**. O editor mostra uma pré-visualização em direto; alterne entre **Pré-visualização móvel** e **Pré-visualização de computador** para verificar as duas.

1. Selecione **Adicionar secção** e escolha o que acrescentar. Os tipos de secção são **Perfil**, **Link**, **Redes sociais**, **Título de secção**, **Texto**, **Imagem**, **Conteúdo incorporado**, **Código QR** e **Links**.
2. Selecione uma secção na pré-visualização para a editar. Arraste a pega para mudar a ordem.
3. Para acrescentar vários links de uma vez, adicione uma secção **Links** e selecione **Gerir links**. Pode filtrar por etiquetas, pesquisar e selecionar links em várias páginas antes de os acrescentar.
4. Para acrescentar um URL que ainda não é um link curto, escreva-o numa secção de link e selecione **Encurtar e adicionar link**. Isto cria um novo link no espaço de trabalho.

As alterações são guardadas num rascunho enquanto trabalha. Os visitantes só as veem depois de publicar.

## Publicar

Selecione **Publicar** quando o rascunho estiver pronto. A página fica disponível no endereço de imediato. Cada publicação cria uma versão a que pode regressar mais tarde; consulte [Personalizar páginas bio](/docs/pt/guides/bio-pages/customizing-bio-pages).

## Partilhar a página

Selecione **Copiar URL** no resumo e cole o endereço nos perfis das redes sociais, na assinatura de e-mail ou em material impresso. Para mudar o nome da página no endereço, abra **Definições da página** no editor e use **Alterar identificador**. Os endereços anteriores continuam a funcionar depois da alteração.

## Estatísticas da página bio

O separador **Estatísticas** de uma página bio mostra os últimos 30 dias: **Visualizações**, **Cliques**, **Taxa de cliques**, **Cliques por bloco** e as principais origens. Os links da página também são contados na página **Estatísticas** do espaço de trabalho.

## Eliminar uma página

No resumo, selecione **Eliminar página de bio** e confirme. O endereço público deixa de funcionar de imediato e fica livre para qualquer pessoa. Os links que estavam na página continuam a funcionar.

## Sugestões

- Coloque primeiro o link mais importante, ou destaque-o.
- Use textos curtos nos botões, para que caibam num ecrã de telemóvel.
- Verifique a pré-visualização móvel antes de publicar, já que as páginas bio costumam ser abertas a partir de uma aplicação social no telemóvel.
