# Guias do Shortn

Estes guias explicam o painel do Shortn tarefa a tarefa: criar e organizar links curtos, preparar códigos QR para impressão, publicar páginas bio, agrupar links em campanhas, ler as estatísticas e gerir o plano. Cada guia usa os nomes que aparecem na aplicação, para que possa acompanhar com o painel aberto.
