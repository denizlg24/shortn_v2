# Guías de Shortn

Estas guías recorren el panel de Shortn tarea a tarea: crear y organizar enlaces cortos, preparar códigos QR para imprimir, publicar páginas bio, agrupar enlaces en campañas, leer las estadísticas y gestionar tu plan. Cada guía usa los nombres que ves en la aplicación, así que puedes seguirla con el panel abierto.
