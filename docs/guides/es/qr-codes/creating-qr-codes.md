# Crear códigos QR

Cada código QR de Shortn abre un enlace corto. El patrón impreso no cambia nunca, así que puedes cambiar adónde lleva el código después de imprimirlo y seguir contando cada escaneo. Esta guía explica cómo crear un código y sacar tu primer archivo.

## Antes de empezar

Cada código QR que creas cuenta para el límite mensual de códigos QR de tu plan, que ves en **Uso** en la barra lateral. Un código puede apuntar a:

- **una URL**: Shortn crea un enlace corto para el código;
- **uno de tus enlaces**: el código queda vinculado a ese enlace y lo abre.

## Crea un código QR

1. Abre **Códigos QR** en la barra lateral y selecciona **Nuevo código QR**.
2. En **URL de destino**, escribe adónde debe llevar el escaneo. Para usar un enlace que ya tienes, selecciona **Elegir un enlace** en **O usa uno de tus enlaces:** y elígelo de la lista. **Usar una URL** vuelve a la opción anterior.
3. Si quieres, añade un **Título** para encontrar el código más tarde, y **Etiquetas**.
4. Selecciona **Crear código QR**.

Se abre el resumen del código. La vista previa del formulario usa un enlace corto de muestra; tu código recibe su propio enlace corto al crearlo.

También puedes partir de un enlace: ábrelo, selecciona su pestaña **Código QR** y luego **Crear un código QR**. El código queda vinculado a ese enlace y lo encontrarás en esa pestaña. Si el enlace ya tenía un código, el nuevo pasa a ser el código del enlace, y el antiguo sigue funcionando.

## Diseña el código

Selecciona **Editar diseño** en el resumen o abre la pestaña **Diseño**. Puedes cambiar los colores, el patrón, las esquinas, la corrección de errores, el logotipo, el marco y la leyenda. La comprobación de escaneo de la misma página te avisa si el contraste es bajo o el logotipo es demasiado grande. Cuando acabes, selecciona **Guardar diseño**.

Los cambios de diseño nunca cambian el enlace que lleva el código. La guía [Gestionar códigos QR](/docs/es/guides/qr-codes/managing-qr-codes) explica cada opción.

## Descarga el código

En el resumen, en **Descargar**, selecciona **Exportar para impresión**:

1. Elige el **Formato**: SVG, PNG o PDF. SVG es vectorial y se adapta a cualquier tamaño de impresión.
2. Elige el **Tamaño** en píxeles.
3. Selecciona **Preparar descarga** y, cuando esté listo, **Descargar archivo**.

La página de exportación indica el tamaño mínimo de impresión recomendado para el código. Para pantallas y correo, abre **JPEG para pantallas** en el resumen.

## Pruébalo antes de imprimir

- Escanea el archivo descargado con dos o tres móviles distintos.
- Deja espacio libre alrededor del código; los marcos y las leyendas se colocan fuera de ese espacio.
- Mantén un contraste fuerte entre el código y el fondo, con el código oscuro sobre fondo claro.
- No imprimas el código por debajo del tamaño mínimo recomendado.
- Añade junto al código una frase corta que diga qué se obtiene al escanearlo.

## Cambia el destino más adelante

Abre la pestaña **Detalles**, cambia la **URL de destino** y selecciona **Guardar detalles**. Las copias impresas siguen el nuevo destino desde el siguiente escaneo. Si el código está vinculado a un enlace, selecciona **Actualizar también el enlace** para copiar también a ese enlace el nuevo destino o título.
