# QR caption font

Geist Regular, unmodified, from https://github.com/vercel/geist-font/tree/10dc7658f13c38a474cde201bb09a4617267545b/fonts/Geist/ttf .

SIL Open Font License in OFL.txt. SHA-256: 85a1c6b18a6b0a06dfe9fd4f6d6a5d4979f74ec861eaef4bc7868b5492b8a117.

font.json embeds the same bytes for the lazy browser caption renderer; supported.json records its Unicode cmap for shared validation. Captions are converted to vector outlines, so exports need no external font requests.
