`better-auth-1.4.18.json` contains a synthetic password hash and signed session
cookie generated by the unmodified Better Auth 1.4.18 email signup handler with
its memory adapter, `shortn_auth_` cookie prefix, and the included fake secret.
Every value is test data. No production identity or credentials are included.

The compatibility test seeds these records into Mongo with BSON identifiers and
fresh database timestamps, then uses the original cookie and password hash
against the current handler. The fixture stays pinned when dependencies change.
